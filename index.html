Spotifyと連携する

最近聴いた曲（最大50曲）をMy Logにインポートできます。
初回のみ下記の設定が必要です。

  1. ターミナルでこのコマンドを実行してサーバーを起動:
    cd ~/Desktop/Claude/MyLog && python3 -m http.server 3000
  2. このページを http://localhost:3000 で開き直す
  3. developer.spotify.com/dashboard でログイン → 「Create app」
  4. App名は何でもOK。Redirect URI に http://localhost:3000 を追加して保存
  5. アプリの「Settings」から Client ID をコピー
Client ID を入力

書き出し（エクスポート）
全データをJSONファイルとしてダウンロードします。GitHubに保存してバックアップとして使えます。
⬇️
読み込み（インポート）
JSONファイルからデータを復元します。既存データと重複しない記録だけ追加されます。

GitHubでの使い方
① 書き出し → JSONファイルをGitHubリポジトリにアップ
② 機種変更・復元時は GitHubからJSONをダウンロード → 読み込み
